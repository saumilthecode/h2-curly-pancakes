Non-In-Place Quicksort

The original group is never rearranged in place.

  1. 1Choose and confirm one pivot rule: first node, last node, or a particular node index. Reuse it for every recursive array.
  2. 2In the highlighted current array, identify the Pivot and create empty Smaller and Larger Arrays.
  3. 3Process the other nodes from left to right and read whether the current node is smaller or larger than the Pivot.
  4. 4Click Move to Smaller Array or Move to Larger Array as indicated.
  5. 5Append Smaller Array + Pivot + Larger Array to the tree. Fully partition the left branch before the right branch.
  6. 6When every array is a base case, reveal all values in the completed tree.
Correction rule: A wrong placement repeats only the current node. Completed partitions and tree branches remain unchanged.
