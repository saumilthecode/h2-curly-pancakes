Merge Sort

First split the list recursively into single nodes. Then merge sorted groups by repeatedly taking the smaller front node.

Merge Sort algorithm

Stage 1 · Splitting
  1. 1Select the current group and divide it as evenly as possible.
  2. 2Recursively split the left group first, then the right group.
  3. 3Stop splitting when every group contains one node.
Stage 2 · Merging
  1. 4Compare the front nodes of the two current sorted groups.
  2. 5Move the smaller front node into the output group.
  3. 6When one group is empty, move the remaining nodes across.
  4. 7Repeat until one sorted group contains all ten nodes.
Correction rule: An incorrect split or merge choice repeats only that step. Completed groups and nodes stay in place.
