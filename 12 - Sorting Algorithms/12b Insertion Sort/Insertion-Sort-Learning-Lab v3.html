Insertion Sort algorithm

Follow these steps for every key.

  1. 1Treat the first node as sorted. Choose the next unsorted node as the key.
  2. 2Select the key, then select its immediate left neighbour.
  3. 3If the key is smaller, swap it left. Otherwise, keep both nodes in place.
  4. 4After a swap, compare the same key with its new left neighbour. Stop at the start or after a “keep” decision.
  5. 5Choose the next unsorted node as the new key. Repeat until all nodes are inserted.
Correction rule: If a pair or swap decision is wrong, repeat only that step. The key and all completed work stay in place.
