Optimised Bubble Sort algorithm

Use this checklist for every pass.

  1. 1Start at the leftmost unsorted node.
  2. 2Select the current node and the node immediately to its right.
  3. 3If the left node is larger, swap them. Otherwise, do not swap.
  4. 4Move one position right and repeat Steps 2–3 to the end of the pass.
  5. 5If a pass has no swaps, the list is sorted. Otherwise, start another pass.
Correction rule: A wrong pair, wrong order, incorrect swap decision, or early finish must be corrected. Repeat that step, then continue—completed work is preserved.
