Selection Sort algorithm

Follow these steps for each unsorted section.

  1. 1Treat the first unsorted node as the current minimum.
  2. 2Select the current minimum, then the next node to its right.
  3. 3If the next node is smaller, make it the new minimum. Otherwise, keep the current minimum.
  4. 4Continue left to right until every node in the unsorted section has been checked.
  5. 5Swap the minimum with the first unsorted node. Repeat for the remaining section.
Correction rule: If a pair, selection order, minimum decision, or placement step is wrong, repeat only that step. All completed work is preserved.
