This installer for H2 Computing (2026) includes the following software:

1. Python 3.13.7, with:
    * Flask 3.1.2
    * JupyterLab 4.4.9
    * Scikit-learn 1.7.2
    * Matplotlib 3.10.6
    * Pandas 2.3.3
2. DB Browser for SQLite 3.10.1
3. Notepad++ 8.9.1

To install:

1. Unblock `h2computinginstall.zip` before unzipping.
2. Right-click `install.cmd` and `Run as administrator`.
