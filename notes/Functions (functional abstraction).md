> [!info] functional abstration
> some nerd thing to call breaking big thing into small things

```python
def <name>(<formal_parameters>):
    <body>
    return xyz
```
- name is name of function
- parameters is like the inputs
- body is actual logic
- # return is the new print
- parameters can be validated with `->` int 
- formal_parameters:<type> means nothing other then you reassuring yourself

Global scope cant use local variables
local scope can access global variables
local scope cant access another local scope
can use same name for diffrent variables if in diffrent scopes
