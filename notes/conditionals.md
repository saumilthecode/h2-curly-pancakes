> [!summary] Quick View
> Use `if`, `elif`, and `else` to choose between different paths in a program.

## Basic Structure

```python
if condition:
    pass
elif other_condition:
    pass
else:
    pass
```

## Keywords

- `if` runs when the first condition is true.
- `elif` checks another condition if the earlier one was false.
- `else` runs if none of the earlier conditions were true.
- `pass` does nothing; it is a placeholder.
- `break` stops the whole loop at that point.
- `continue` skips the rest of the current loop iteration.
